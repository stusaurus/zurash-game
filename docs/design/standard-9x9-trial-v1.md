# 新スタンダード候補 v1 — 9×9／星7／壁10／4個先取

## 背景：初めての人の実プレイ評価（2026-10-31）

現行の初期設定「はじまりの氷原」（7×7／星5／壁8／3個先取）では、
あまり考えずに勝負が終わり、展開が単調に感じられた。
大きな盤面の方が壁の動かし先を考える余地があり、星も少なく感じられた。

この**人間の評価**をゲーム設計の最優先の根拠として扱う。光の粒やコマンド装飾を増やしても根本問題を解消しない。

## 方針

- 「はじまりの氷原」は削除・改名せず、7×7／星5／先取3の入門版として残す。
- A〜Eの5研究面も設定・配列番号を変更しない。
- **新標準の候補**を、独立した「【試遊】」9×9／星7／壁10／4個先取として追加する。
- 手番の基本構造（壁移動は省略可→1方向に止まるまで滑走→止まった星のみ取得）は変更しない。
- CPU、星取得、Undo、勝敗判定、既存のトリケン・氷の世界は共通の実エンジンを使用する。
- 現時点では**デフォルト（はじまりの氷原）を切り替えない**。公平性・遊びの質の評価と本人の比較試遊を通過したら標準設定へ昇格する。

## v1盤面

- 大きさ：9×9、81マス。初期コマ：72／8。
- 星：6, 29, 34, 40, 46, 51, 74（7個）。
- 壁：1, 9, 12, 28, 30, 50, 52, 68, 71, 79（10個）。
- 勝利条件：星4個先取。
- 配置は180度回転対称、開始位置と星・壁は重複なし。
- 初手に壁を動かす／省略する複数の合法選択肢を維持し、初手得点の容易さを抑えるよう構成。

**注意：見かけの180度対称性と合法手数は、先攻後攻の公平性や実際の戦略性の証明にはならない。** 今回の候補は自動生成集合の中の1例をスクリーニングしただけで、最適解ではない。

1. 実際の人間の試遊では、勝敗だけでなく「どの壁を動かすか悩んだか」「相手の次の星を予想したか」「同じ星へ直行するだけになっていないか」「もう一回したいか」を記録する。
2. 初心者・大人の2人対戦と、CPUふつう／つよいを比較する。初期配置は固定し先手を入れ替える。
3. 公式エンジン・異なるCPU方策で、得点までの手数、逆転、先手差、長期無得点、未決着を分析する。未決着を引き分けとして数えない。
4. スマホ320／390pxで81マスをタップできるか、拡大やスクロールを伴っても不快でないか確認する。
5. **基準は「選択肢が多いこと」だけではない。** 利害の異なる選択肢が複数あり、結果を理解でき、何度も試したくなるかを確認する。

## 採用判定

v1を即時に標準へ切り替えない。比較で単調さが減り、長期化や公平性の重大な悪化がなく、本人の試遊で明らかな改善が確認できたときにのみ、初期選択を9×9へ切り替える。
