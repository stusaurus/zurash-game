# ズラッシュ！ スマホ操作QA — 第15段階

対象：Draft PR #49（`design/zurash-mobile-ice-integration`）。正式採用した背景・ロゴ・トリケンと実ゲームエンジンを維持。

## 自動テスト（iPhone相当WebKit / WebKit / Chromium）

- 320×568、375×667、390×667、430×740：横方向の不要なページはみ出しを許容しない。
- 小さい画面では、ゲーム盤を不自然に縮めず、スクロール後に実十字キーの操作が可能であること。
- `env(safe-area-inset-bottom)` に対応する画面下部余白を確保すること。
- ボタンの長押しで文字選択が発生しないこと。
- タップ開始で見た目だけ反応し、クリック確定前に手番が進まないこと。
- ドラッグが12pxを超えると押下演出を解除し、スクロールやキャンセルを邪魔しないこと。
- 実クリックで合法な滑走だけを実行し、手番・Undoが従来どおり機能すること。

## 実機で確認する項目（**未実施**）

画面のスクリーンショットと自動WebKitテストでは、実機の触感や描画のコマ落ちは保証できない。

1. iPhone Safariで開始前画面を確認。採用済みロゴが欠けない。対局開始後は盤面と右十字キーが主役になる。
2. 片手で右十字キーを10回押す。親指でボタンが押せ、手や指で盤面の重要情報を覆わない。
3. ボタンを押したまま指を滑らせ、離す。移動が誤確定せず、押下演出が解除される（必要に応じて壁移動操作時も確認）。
4. Safariで画面を上下にスクロールし、ホームインジケータと「動き」切替の干渉がない。
5. 「動き：ON/OFF」を切り替え、1マスと長距離の滑走が自然に見えるか。特に壁をずらした直後、星を獲得した直後、Undo直後を確認。
6. 小型画面や横向きで、ボタンの隠れ・意図しないスクロールがないか確認。問題があれば実機名と画面サイズを記録。

## 合格基準・安全策

- スマホ専用Playwrightとトリケン動作／結果演出テストが成功していること。
- 総合Game qualityテストも独立に確認すること。以前のiPhone WebKit中間フレーム計測失敗（rAFサンプル2点）は、実機の滑らかさを保証する根拠にはならないため、成功と断定しない。
- 画面・操作の正式採用はユーザー承認後。承認前にmainへのマージや公開はしない。
- ルール、AI、勝敗条件、盤面データ、トリケンアセットはこのQAで変更しない。
