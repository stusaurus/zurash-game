## 判断の原則
1. 重要な判断には保存棋譜、再現手順、対照群を必須とする。
2. AI自己対戦で早く終わることと、人間が5〜10分で楽しめることは別の要件。
3. 一度不採用となった技術は新しい根拠がない限り正式採用しない。
4. 研究/テスト環境から`main`へは承認済みの限定差分だけを取り込む。
5. 各リスクを解消した根拠（CI URL、実機記録、棋譜ID、PR番号）を追記する。
