# ズラッシュ！ — ZURASH!

**壁をずらせ！ 勝利へ滑れ！**

トリケンと遊ぶ、2人用アブストラクト戦略ボードゲーム。TIRANON GAMES。
『星の迷宮』とは独立したプロジェクトです。旧リポジトリのソース・履歴・ブランチは変更していません。
指定された試作HTMLは指定パスで取得できなかったため、依頼文の正式仕様から再構築しました。

## 遊び方

1. 7×7マスに、2人のコマ・動く壁・5個の星。
2. 自分の番に、壁を1個だけ上下左右へ1マス移動。省略もできます。
3. 自分のコマを上下左右の1方向へ滑らせます。壁・相手・盤端の手前まで止まれません。
4. **停止したマス**に星があれば獲得。通過では取れません。
5. **星を先に3個**取った人の勝ち。

壁は盤外・壁・星・コマのあるマスへ動かせません。
両者に滑走方向が少なくとも1つ残ることを、壁移動直後と滑走直後に確認します。
局所的な完全閉じ込めを禁止します。星への到達可能性や全局的な膠着の数学的保証ではありません。
同一局面が3回現れたら案内しますが、自動の引き分け・ターン制限はルールに追加していません。

## 操作

光る壁→移動先→停止マスまたは方向ボタン、の順でタップ。
壁移動を省略するときは「壁を動かさずに滑る」。
CPU対戦／同じ端末の2人対戦に対応。対戦モード変更は新規対戦ダイアログで確定します。
「戻る」は壁移動中ならその手番の開始時、CPU対戦では通常あなたの直前の手番へ戻ります。
CPU先手で、人間がまだ一度も指していない場合はCPUの初手前へ戻り、CPUが再思考します。
新しい対戦では配置と先手を選べます。再戦は同じ設定です。

## 起動とテスト

ランタイム依存なし。静的HTTPサーバーでリポジトリ直下を配信してください。
ES modulesとWeb Workerを使うため、`file://`で直接開かずHTTPで配信します。

```sh
python3 -m http.server 8080
# http://localhost:8080/
npm test
npm run check
PAIRS=20 npm run balance
```

ブラウザテスト（開発時のみ依存あり）：

```sh
npm ci
npx playwright install --with-deps chromium webkit
npx playwright test
```

CIでChromiumとWebKitの実操作を検証し、320 / 390 / 768 / 1200pxのスクリーンショットとHTMLレポートをartifactに保存します。
WebKitはiPhone実機Safariの代替検証であり、実機のタッチ感・性能を保証しません。

## 構成

- `src/engine.js`: DOM非依存のルール、合法手、盤面、滑走、閉じ込め判定
- `src/ai.js`: seed付き乱数、星への滑走距離・得点差・相手の取得機会を評価するCPU
- `src/cpu-worker.js`: CPU思考をUIスレッドから分離。失敗時は1手評価へフォールバック
- `src/app.js`: 操作、短い滑走、取得・勝利表示、履歴、手番管理
- `style.css`: レスポンシブUI、陣営別の枠・数字、reduce-motion対応
- `tests/`: ルール・不変条件テスト、実ブラウザ操作テスト
- `reports/balance.json`: 条件・seed・先後別成績・手数・計測上限を含む検証データ

CPUは候補手を評価後、上位8手について相手の応手を読む2手先minimaxです。
全幅探索ではなく、最善手や人間同士の公平性を保証しません。
3つの初期配置は180度回転対称です。初期配置の対称性は先後の公平性の証明ではありません。
