# ズラッシュ！「壁2個カレー」必勝法の研究（2026-10-18〜19）

## 研究の問いと判定ルール

- 対象は**こおりの回廊・7×7・星3個先取・カレー取得の次の自分の手番に別々の壁2個を1マスずつ動かす**実験版。初期カレー[21,27]と[5,43]で比較。
- **AIの連勝≠必勝法。** 真の「初期局面からの必勝」には、相手のすべての合法応手を考慮し、有限の手順または一般的な証明によって勝利を強制できる必要がある。
- 本報告では検証対象を明確に限定し、①中盤から3半手以内の強制勝利、②初手から3半手以内の星獲得の強制、③後手のミラー戦法の可否を調べた。
- **結論：初期局面からの完全必勝法は発見も不存在証明もしていない。局所的な強制勝利は2件、相手の全合法応手を用いて再現確認した。**

## 1. 強制勝利の証明書A（中盤・星0対2）

[強制勝利探索CI #39171764732](https://github.com/stusaurus/zurash-game/actions/runs/39171764732)
（最初の発見：[CI #39171657280](https://github.com/stusaurus/zurash-game/actions/runs/39171657280)）。

- カレー：[21,27]、先手プレイヤー1。9半手後、プレイヤー2の番。
- 手番側P2は**星2個**、相手P1は**星0個**。残りの星は[17,24,45]。
- 盤面：壁[14,2,18,22,26,36,37,40]、コマ[P1=21,P2=31]、未取得カレー[27]、パワー[P1=1,P2=0]。
- P2が**壁を動かさず、上へ滑る**と、次のP1の合法応手は**683通り**。
- その683手すべてについて、P2が次の自分の番に3個目の星を取って勝てる合法手があることを列挙確認。
- `tests/two-wall-forced-win-proof.test.js` には、初期局面からの**9手すべての合法手再生と683防御全件テスト**を固定。
- これは「上へ滑ると次々手で詰み」になる**到達可能な局所強制勝ち**。この局面に初手から相手の意思に関係なく到達できるわけではない。

## 2. 強制勝利の証明書B（中盤・星2対1）

[対戦中の勝ち筋探索CI #39172539056](https://github.com/stusaurus/zurash-game/actions/runs/39172539056)。
証明書の独立再現は[CI #39172752290](https://github.com/stusaurus/zurash-game/actions/runs/39172752290)で **全42件のテスト成功**。

- カレー：[5,43]、**プレイヤー2が先手**。17半手後、プレイヤー1の番。
- P1が星2個、相手P2が星1個。残りの星[24,31]。
- 盤面：壁[4,9,13,22,32,35,45,47]、コマ[P1=11,P2=3]、カレー[5,43]、パワー[0,0]。
- P1が**壁の配列index1の壁をセル16へ移し、下へ滑る**と、P2の合法応手は**49通り**。
- その49手すべてについて、P1に3個目の星を取れる合法手が存在することを列挙確認。
- `tests/two-wall-contested-forced-win-proof.test.js` に初期局面からの17手再生と49防御全件の独立再検証を固定。テストの先手設定を最初に取り違えたが、修正して全件通過した。
- **この証明書ではカレーは未取得のままで、壁2個のパワーも使っていない。** カレー自体に破壊的な必勝効果がある証拠ではない。

## 3. 初期局面からの序盤の「星を確実に取る手」

[序盤総当たりCI #39172078671](https://github.com/stusaurus/zurash-game/actions/runs/39172078671)、テスト41/41成功（17半手証明書追加前）。

| 対称カレー配置 | 先手とする陣営 | 初手合法手の総数 | 初手で星取得可能 | 3半手以内に星1個を強制する初手 |
|---|---|---:|---:|---:|
| [21,27] | P1 | 52 | 0 | **0** |
| [21,27] | P2 | 52 | 0 | **0** |
| [5,43] | P1 | 53 | 0 | **0** |
| [5,43] | P2 | 53 | 0 | **0** |

相手の**少なくとも1つの合法応手**が3半手以内の得点を妨害できることを初手の全候補で確認。実際には602回の合法手列挙呼び出しで終わり、全4ケースとも探索打切なし。

これは**星3個先取の初期局面からの必勝法の不存在証明ではない**。長い手順の必勝戦略を否定できない。

## 4. 後手のミラー戦法（180度反転してまねする）

[ミラー合法性CI #39172200376](https://github.com/stusaurus/zurash-game/actions/runs/39172200376)：初手の先手全合法手に対し後手が対称性を回復できる手が存在。
- [21,27]：**52/52**、[5,43]：**53/53**。どちらのプレイヤーを初手にしても同様。
- 復元した状態からサンプルした2巡目も、各配置・先手条件で**514～515ケース、ミラー復元が可能**。
- しかし、盤面の対称性を維持できても「後手が勝てる」ことにはならない。

[ミラー対戦テストCI #39172383371](https://github.com/stusaurus/zurash-game/actions/runs/39172383371)：後手は可能ならミラー手から乱択、不可ならgreedyに切り替え。対戦相手は先手CPU、配置2種を合算。
- **greedy先手相手**：先手93勝・後手3勝（96局）。
- **search先手相手**：先手84勝・後手10勝・未決着2（96局）。
- 無作為な先手相手は未決着が多く、強さの評価には使えない。
- **したがって、検証した素朴な「後手ミラーしていれば勝つ」戦法は、先手のgreedy/search戦略に大きく負けた。**
- これはミラーの応手選択を最適化していない試験であり、あらゆる鏡戦法や後手の必勝法まで否定したわけではない。

## 5. カレーのパワーを使った強制勝利は？

[パワー所持中の追加探索CI #39172752290](https://github.com/stusaurus/zurash-game/actions/runs/39172752290)。
- カレーを所持し、**自分が星2個・相手が星1個以上**という条件で、中盤の強制勝利を追加探索。
- 設定した2配置・3種類のCPU・最大25半手のサンプルでは、この条件に合う局面が**0件**だった。従って強制勝利の検証も0件。
- **カレーでの強制勝ちがないという結論は出せない。** この試験では条件に合う局面を一度も観測できなかっただけ。

## 6. ゲームの品質への意味

- **中盤の強制詰みは、読み合いの成果として成立するならむしろ望ましい。** 2つの証明書は固定手順がどう作られるかを理解する手掛かりになる。
- **懸念すべき必勝法**は初期配置から片方が何をされても勝てる戦略や、盤面を無視した単純手順の繰り返しで一方的に勝つ戦略だが、今回はそこまでの数学的解析には到達していない。
- ゲームには明示的な反復・引き分け終了条件がないため、**無限に回避する戦略の扱い**が全局面のゲーム理論的解決を難しくする。ルールを変更する前に再訪可能性を調べるべき。
- 強いカレー「**次の自分の手番に別の壁2個を1マスずつ動かせる**」はこの調査では変更しない。
- 本番へのマージなし。別ゲーム『星の迷宮』、3・4人戦、公開済みサイトには一切手を加えない。

## 研究コード
- `scripts/two-wall-forced-win.js`：限られたサンプル局面に対して、**自分の候補手→相手の全合法応手→自分の直接勝利**を列挙する証明エンジン。証明書を別パスで再検証。
- `scripts/two-wall-opening-threats.js`：全初手の3半手以内の星獲得強制を反証する相手の手を探索。
- `scripts/two-wall-mirror-recipe.js` と `scripts/two-wall-mirror-policy.js`：合法な180度反転の応手と、その戦法が実際に勝てるかの試験。
- テスト：`tests/two-wall-forced-win-proof.test.js`、`tests/two-wall-contested-forced-win-proof.test.js`、`tests/two-wall-opening-threats.test.js`。
- 詳細の証明書・全候補局面のJSONは各GitHub Actionsのartifactに90日保存。

**最終判定：初期配置からの先手／後手どちらの必勝法も「未証明」。9手目と17手目の到達局面には、相手がどの合法手を選んでも防げない中盤の強制勝利が存在する。**
