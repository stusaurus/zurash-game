## 全件の基礎評価

各盤面について、両側の初期合法手数・移動可能性・固定壁の星距離・取得可能な初手・壁操作なし取得・停止マスの多様性・動かせる壁・1手評価の近似有力手数を記録。地形の関節点、狭いマス、充填率、縦横比、地形／星／壁の回転対称性も保存した。

関節点は「歩行可能な地形グラフ」の性質で、滑走や壁操作を含む通路支配の証明ではない。固定壁距離が無限でも、壁操作を含む取得不能と断定しない。「有力手」は1手評価の最高値から25以内という近似で、最善手集合ではない。

basics.json.gzは全1,135件。positions.json.gzには全候補での探索・棄却理由・seed・静的評価・親IDを記録。全候補を高コストAIへ送らず、11形状の既存研究例を残し、星数・先取数・大きさが異なる3例を加えた14親から深めた。

## 手番・物理的位置・AIの独立した実験計画

1つの盤面・seed・AI組につき、開始する論理プレイヤー2通り × 物理的な初期位置の入替2通り × AI担当の入替2通り = 8条件。論理プレイヤー、物理的な初期位置、AI名、RNG状態を独立に保存する。勝者から「先攻勝ち」と「初期位置0側勝ち」を別々に算出し、初期位置×開始手番×AI担当の交互作用表を保存した。

IDは完全な盤面定義・段階・seed・AI組・各交換・比較実験のルールからSHA-256で作る。同一IDの再実行は未解決の継続であり、新しい局数ではない。継続前prefixのSHA-256とRNGを照合した。

使用方策は星優先、位置、守備、混合、探索、production強CPU。初回の軽量比較seedは610001、深める段階は610007。初回holdoutは9700003 / 9700033 / 9700067 / 9700103。追加位置探索の訓練は6300013、追加holdoutは9800003 / 9800033 / 9800059 / 9800083で、AI組も変更した。

初回holdoutを見て追加探索を行ったため、同じholdoutを再利用せず、新しい4seedを用意した。各段階の候補を訓練結果だけで固定してから、その段階のholdoutを実施する。freezeファイルを保存し、holdoutの結果で候補を入れ替えない。

## 初期位置の自動改善

まず全件に静的な距離・到達・移動可能性の差を使って位置案を作成。その後、14親について最大8案ずつを強めのAIで比べ、先攻偏りと位置偏りの大きい方を抑え、未解決率と初手の多様性も使って次の検証案を決めた。元の星・壁・形状・先取数は固定した。

改善判定には、両側16局以上の決着、32対応条件、4独立seed群、位置偏り減少のbootstrap下限が正、未解決率が悪化しない、先攻偏り指標の増加が0.10以内という条件を使用。最後の許容幅は事前の探索基準であり、両方の偏りが完全に改善したという意味ではない。多重比較補正をしていないため、以下は暫定的な条件付き結果である。

位置偏り指標 = |位置0側勝利数−位置1側勝利数| / 決着局数。0が均衡、1が片側全勝。未解決は分母から外れるので、未解決込みの可能範囲も別に記録する。

T字の初回位置案では位置偏りの減少と先攻偏りの悪化が同時に起きた。そのようなトレードオフも記録し、改善と一括評価しない。T字という形状全体を除外していない。元のT字の「特定初期位置が必勝」という4手以内の証明と、他の配置のAI観測も区別する。

8種類（初期位置、星配置、壁配置、星数、壁数、先取数、形状の一部、複合）の変異を実装。初回は128試行、合法な新規子102、棄却19、既存と同一定義7。親を上書きせず、全試行に親・種別・seed・理由を保存した。

Pareto軸は先攻偏り、位置偏り、未解決率、観測初手数、逆転、サンプル中の壁依存取得、深さによる選択差、外接面積による操作コストの代理値。1つの点数で最良を選ばず、形状と配置の多様性を残し、55面すべてを研究ライブラリに保持する。面積・近似手数・AI観測を、人間の操作しやすさや面白さの実証とはしない。

## 対局結果・決着・限界

通常ルールの4,864局は先攻1,911勝・後攻1,624勝・未解決1,329局。盤面とAIの混合集計であり、ズラッシュ全体の先攻率推定として使わない。反復・無得点区間、リード交代、勝利目前からの逆転も棋譜から保存した。

対応区間はseedを単位に再標本化し、同じseed内のAI組・位置・開始手番を一緒に扱う。4群にすぎず、決着した局の選択、多数候補の比較、方策依存、予算による打切りの影響がある。未解決込みの最終可能範囲と記述的Wilson区間も保存。未解決が多い盤面に公平なラベルを付けない。

120手・反復を正式な終了条件にしていない。研究用の時間／メモリ／手数予算で打ち切り、棋譜とRNGを保存する。追加の90秒予算で227局を継続し123局が決着した。継続後の成績に更新したが新規局数は増えていない。

壁の比較は6盤面について同じ条件の通常操作・壁操作なしを比べ、深さ比較も別に行った。計144局。壁操作なしはルール介入であり、通常ゲームの勝率へ混ぜない。比較方策は同じ評価関数の1手／beam4の2手で、production強CPUそのものではない。小さい比較標本から壁の一般的因果効果や人間の戦略性を証明しない。

## 盤面ラボと品質

「新しい対戦」→「盤面ラボ」→「名盤研究・全件の基礎評価を読み込む」。全件の基礎評価と55研究盤面をオンデマンドで表示し、形状・ID・観測特徴で検索できる。先攻・後攻と物理的位置別成績、独立条件、未解決、対応区間、親子比較、特徴、注意を表示する。研究盤面をCPU／2人で遊べる。編集・先取数変更をしたら、その場で表示中の研究成績を消し「AI未検証」に戻す。

スプリント・A〜E・ランダム生成・エディター・JSON・Undo・再戦を維持。単体100件成功（従来86＋追加14）、ローカルChromium27件成功（従来26＋追加1）。CIは3環境81ブラウザと通常回帰・厳密探索を実行し、最終結果はPRに記録する。

全5,008局を再生して統計と照合。勝者・物理的位置・AI割当・実験ID、取得・壁操作・リード交代・勝利目前逆転を独立に再計算した。294,931手と227継続prefixを検証し、SHA-256をverification.jsonに保存した。

## 再開方法と残課題

- `npm run research:discovery`：元コーパス全件評価、変異・初回比較を再開。
- `npm run research:positions`：物理的に異なる位置案をAI選択し、新しい独立条件で再開。
- `CONTINUE_MS=90000 node scripts/discovery-continue.js`：有望性のある未解決holdoutを継続（新規0）。
- `DISCOVERY_RESUME=0 npm run research:discovery` と同条件の `research:positions`：再集計のみ。
- `npm run research:discovery:report` → `npm run research:discovery:verify`：統合ライブラリと照合。
- `DISCOVERY_REPORT` で保存先を指定。既存freezeは再利用し、holdoutを見て選抜し直さない。新しい研究計画には別保存先と新しいseed設計が必要。
- `board-discovery.yml` は手動起動のみ、ジョブ20分。主研究12分、追加位置6分のプロセス上限。Nodeヒープ640MB・対局側512MB。通常CIに大量対局を入れない。
