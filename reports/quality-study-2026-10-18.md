# ズラッシュ！公平性・多様性・品質監査（2026-10-18）

## 検証方法
main のCPU強化版（コミット d52bdc8b80718f4bffeb32388104b58425637aff）に相当するルールとAIを使用した。
3配置 × 3方針組合せ × 160局 = **1,440局・計57,139手**を計測。
同じseedで先手を0/1と入れ替えるペア設計（各条件80ペア）。
最大120手で打ち切り。打ち切りはゲーム内ルール上の「引き分け」ではない。
ペアは独立標本ではなく、実験AIの勝率は人間の公平性を保証しない。

| 配置 | 方針 | 先手 / 後手勝利 | 未決着 /160 | 平均手数 | 初手種類 |
|---|---|---:|---:|---:|---:|
| はじまりの氷原 | 星優先同士 | 97 / 63 | 0 | 11.7 | 81 |
| ふたつの谷 | 星優先同士 | 81 / 79 | 0 | 11.4 | **2** |
| こおりの回廊 | 星優先同士 | 82 / 78 | 0 | 10.9 | 90 |
| はじまりの氷原 | 無作為同士 | 36 / 27 | **97** | 97.4* | 80 |
| ふたつの谷 | 無作為同士 | 43 / 31 | **86** | 96.3* | 80 |
| こおりの回廊 | 無作為同士 | 26 / 41 | **93** | 97.1* | 88 |
| はじまりの氷原 | 星優先 vs 無作為 | 80 / 80 | 0 | 11.7 | 81 |
| ふたつの谷 | 星優先 vs 無作為 | 80 / 80 | 0 | 9.2 | 41 |
| こおりの回廊 | 星優先 vs 無作為 | 80 / 80 | 0 | 11.4 | 89 |

*未決着局の120手を含むため無作為同士の平均は決着時間ではない。星優先vs無作為は星優先側が全160局勝利した結果。*

## 公平性の解釈
- 星優先同士の先手勝率は、標準60.6%、谷50.6%、回廊51.3%。
- 同seedペアを再標本化するブートストラップ（80ペア×10,000回）の95%区間は
  標準53.1–68.1%、谷43.1–58.1%、回廊43.8–58.8%。
- **標準で星優先AIの先手優位が疑われるが、別AIや人間対人間で未検証**。
  幾何学的回転対称性だけでは先手公平性を証明しない。

## 多様性・戦術
- 谷は最初の星を取る手の中央値が1手（標準5、回廊4）。
  星優先AIの初手が2種類に集中し、序盤の分岐が少ない可能性。
- 星優先同士で壁移動は約98〜100%。「壁を動かさない」選択が
  本当に戦術として機能する場面は追加で検証する必要がある。
- 無作為同士で54〜61%が120手でも終わらないため、初心者向けの
  星の狙い方・止まり方を示す説明の改善が必要。
- 別の標準配置100局では強化CPUが星優先AIに88勝12敗（平均15.7手）。
  ただし強いAI同士の小規模試験では80手未決着があり、
  単純なCPU勝率では面白さやテンポを保証できない。

## 追加した品質保証
- 配置の180度対称性に加え、**プレイヤー交換＋盤面180度回転**をした
  途中状態の合法手と着手後結果が一致することをテスト。
- 初期配置とseedと方針と上限を明示できる品質監査スクリプトを追加。
- 記録値は対局条件とAIに依存する。人間の10〜20分、
  逆転の納得感、再戦意欲は実プレイで別途検証する。

## 変更の採否
- **採用**：監査基盤と対称性の回帰テスト。
- **保留**：新しいルール・補正・カード・星の数変更・強制決着。
- 次段階は強化AI同士の長期戦原因、序盤の選択肢が少ない谷の再設計、
  人間同士の接戦率・再戦意欲の記録を優先する。

## 再実行
監査スクリプトは公開環境に影響を与えない。次のコマンドで
reports/quality-audit.json に集計結果を書き出す。


```sh
PAIRS=80 MAX_PLIES=120 MATCHUPS='greedy/greedy,greedy/random,random/random' npm run quality:audit
PAIRS=3 MAX_PLIES=80 MATCHUPS='search/search,strong/strong,strong/search' npm run quality:audit
```
