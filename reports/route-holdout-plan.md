# 壁移動込み経路AI：固定後検証計画

候補実装はコミット `2ff5a21` の `src/route-ai.js`。予備試験を見た後、このコードを固定して以下を実行する。結果を見て候補を調整した場合、このholdoutを未使用の検証として再利用しない。

- 予備：SEED_OFFSET=1000001、4 seedペア/配置、上限120手。route-progressは対現行24局で22勝1敗1未決着。予備結果は最終根拠と分離。
- 固定後：SEED_OFFSET=4000037、30 seedペア/配置、160手上限。
- 各配置で route/strong、route-progress/strong、route/route、route-progress/route-progress、strong/strong。
- 3配置×5組×60局＝900局。同じseedを先後・候補間で対応比較。3配置を別プロセスで実行し、全局を保存・合法再生する。
- routeは壁移動込みの実取得可能性を使う。route-progressはそれに「コマ・得点・残星が同じなのに壁だけ変える反復」への小さな評価ペナルティを加える。ルール上の禁止・自動決着ではない。

## 採用条件
1. 対現行で全配置の勝ち数が負け数を上回り、全配置合計で未決着を非勝利と数えた勝率の対応seedブートストラップ95%下限が50%を超える。
2. 自己対戦の未決着率・上限を含む観測平均手数が現行より全体で改善。配置単独の未決着率が5ポイントを超えて悪化しないこと。対応seed比較の区間も報告する。
3. 合法手ゼロ0、即勝利・回避できる即敗北の固定テスト成功、全着手再生成功。
4. 処理時間とブラウザ操作を確認し、6秒watchdogの発動・操作停止・古い応答混入などの回帰がないこと。
5. 公平性・初手集中・接戦・壁省略も報告。AIの成績を人間の公平性・面白さへ読み替えない。

routeとroute-progressの比較は補助的な機能除去試験。改善根拠がない機能は採用しない。人間の楽しさ・実機Safariは別途検証が必要。
