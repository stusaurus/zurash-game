# 全5盤面の継続・独立比較（2026-10-22）

全5盤面を維持。スプリントと画面の配置を維持し、代替配置を独立検証した。正式採用・マージ・本番公開は行っていない。

## 方法

前回の再選抜136局を、元のAI・RNG・棋譜から追加4秒／4,096手まで継続。初回seed60001による訓練結果から未解決数と先後差のPareto前線を作成し、各サイズで既存1面＋代替1面を事前選択した。異なるサイズの候補を削除する選抜ではない。

選択に使用していないseed71001〜71003で、探索・混合・production CPUの3つの自己対戦、両開始手番を比較。各配置18局、10配置で180局。各局6秒／4,096手、メモリ512MiB上限。前回より計算予算を増やしたが、まだ計算不足を十分排除したとはいえない。

先後勝率だけでなく未解決とAI別結果を分離。対応付きbootstrapと保守的なcluster区間は既存の検証済み統計関数を利用。9clusterしかないため区間は広く、点推定で公平性を認定しない。120手・反復を正式な終了条件にはしない。

## 検証と限界

継続136局のprefixと最終局面を照合し、独立180局を合法再生した。訓練未解決は80件から39件へ変化。前回536局と重複しない新規対局は180局で、累計716局。継続136件を新規対局として数えていない。

代替選択は4局の訓練に依存する小規模探索。最適化範囲は前回生成した124合法候補の一部であり、星・壁・勝利条件・初期位置を広範囲に最適化し終えたものではない。初期位置は対角のまま。人間の所要時間・小学生の操作性・勝敗の納得感は未認定。

現行を置き換えるには、独立標本の追加、AI・探索予算を変えた追試、未解決対局の継続が必要。盤面サイズごとの可能性と固定配置の問題は区別する。

## 再現

```sh
node scripts/five-board-followup.js
node scripts/five-board-followup-report.js
```

`training.jsonl.gz` と `independent.jsonl.gz` に全棋譜・状態・RNGを保持。壁時計予算の再実行では中断手数は変わり得る。保存checkpointからの継続と、固定手数での再現性は前回のテストを参照。
